# figma-classes-mumbai-live-projects-placement

A playful, colorful single-page landing site answering "Best Figma Classes in Mumbai with Live Projects & Placement", built around Figma's own multicolor brand palette and a signature multiplayer-cursor canvas mockup.

## Highlights

- Signature visual: an animated Figma-style canvas card with roaming multiplayer cursors, echoing Figma's own real-time collaboration feature.
- Confetti dots in the hero using Figma's actual brand colors, red, orange, purple, blue and green.
- A horizontal, scrollable roadmap strip placing the Figma course inside the bigger UI/UX career picture.
- A dedicated warning-style card pointing to the honest "read before you enroll" guide, distinct from the other blog cards.
- Fully responsive grid layouts, mobile-friendly nav, and touch-safe tap targets down to small phone widths.
- Fully clickable cards, the course and all three blog links are wrapped as single links throughout the page and footer.
- Zero dependencies, plain HTML and CSS, works out of the box on GitHub Pages.

## Run it locally

```bash
git clone https://github.com/<your-username>/figma-classes-mumbai-live-projects-placement.git
cd figma-classes-mumbai-live-projects-placement
open index.html
```

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to Settings then Pages.
3. Under Build and deployment, set Source to the main branch, root folder.
4. Save, your page will be live at https://your-username.github.io/figma-classes-mumbai-live-projects-placement/

## Tech Stack

- HTML5, CSS3 (custom properties, grid and flexbox, keyframe animations)
- Google Fonts, Manrope and Sora
